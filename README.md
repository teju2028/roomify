# Roomify – Roommate Matching Platform

Roomify is a web-based roommate matching platform that helps users find compatible roommates based on their lifestyle preferences and personal requirements. The platform enables users to create profiles, set preferences, and discover suitable roommate matches through a preference-based matching system.

## Features

- **User Authentication**
  - Implemented user registration and login functionality for secure access.

- **Profile & Preference Management**
  - Allows users to create profiles and specify preferences such as budget, cleanliness, sleep schedule, and lifestyle choices.

- **Roommate Matching**
  - Matches users based on their selected preferences to suggest compatible roommates.

- **Interactive Dashboard**
  - Provides an intuitive interface for managing profiles and viewing roommate recommendations.

## Tech Stack

- **Programming Language:** Python
- **Framework:** Streamlit
- **Database:** MongoDB

## Project Workflow

1. Users register and create their profiles.
2. Users provide their roommate preferences.
3. Preference data is stored and processed using MongoDB.
4. The matching system compares user preferences.
5. Compatible roommate suggestions are displayed through the dashboard.
